\# yt-gemini-scribe



YouTube動画の字幕を抽出し、Gemini APIを用いて要約を生成、Markdownファイルとしてローカルに保存するChrome拡張機能（Manifest V3）。



\## 概要



本システムは、YouTubeの動画リンク上からコンテキストメニュー（右クリック）を介して起動する。対象動画を非アクティブタブとしてバックグラウンドで一時的に展開し、ページコンテキスト内のJavaScriptオブジェクトから直接字幕データを抽出する。抽出されたテキストはGemini APIへ送信され、構造化された要約データ（`.md`ファイル）としてローカル環境にダウンロードされる。



\## アーキテクチャと設計方針



\*   \*\*DOM/JSコンテキスト実行によるデータ抽出\*\*:

&#x20;   単純なHTMLソースのフェッチおよび正規表現による抽出を排し、正規のページ読み込みプロセスを経てメモリ上に生成される `window.ytInitialPlayerResponse` オブジェクトから直接字幕URLを取得する。これにより、UIのDOM変更に対する耐性を確保しつつ、正規のブラウザナビゲーションをシミュレートしてボット検知リスクを最小化している。

\*   \*\*バックグラウンド処理の完結\*\*:

&#x20;   処理はすべてService Workerおよび一時的な非アクティブタブ内で非同期に実行される。ユーザーの現在のブラウジング操作を一切阻害しない。

\*   \*\*APIキーのローカル分離（セキュリティ）\*\*:

&#x20;   ソースコードへのAPIキーのハードコードを回避するため、設定ファイル（`config.js`）をバージョン管理から除外する設計を採用している。



\## 前提条件



\*   Google Chrome (Manifest V3をサポートするバージョン)

\*   Gemini API キー
